# Countdown Timer

A beautiful JavaScript countdown timer that counts down to **December 17, 2025, at 11:45 PM Qatar Time**.

## Features

- Real-time countdown display showing days, hours, minutes, and seconds
- Responsive design that works on all devices
- Beautiful gradient background with glassmorphism effect
- Automatically handles Qatar timezone (UTC+3)
- Displays a celebration message when the countdown ends

## How It Works

The countdown timer calculates the time difference between the current time and the target date (December 17, 2025, 11:45 PM Qatar Time). It updates every second to show the remaining time in days, hours, minutes, and seconds.
